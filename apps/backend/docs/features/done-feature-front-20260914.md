## 変更の詳細
- 得点ヒストグラムは各棒に「{数字}試合」と書かず、横軸を得点、縦軸を全試合に対する割合（0〜100%）として表示する。
- 本塁打の内訳は総本塁打数を分母とした割合（%）のみを表示する。積み上げ棒には文字を書かず、色・種別・割合を対応付ける凡例を表示する。
- 件数が0の本塁打種別は棒・凡例ともに表示せず、総本塁打が0の場合は「本塁打なし」を表示する。
- デスクトップでは得点分布へ優先的に横幅を割り当て、狭い画面では結果カードを縦積みにして、グラフ・凡例・戦術の値が切れないようにする。
- 戦術の成功数は、比較棒と数値を分離し、数値が棒の中で切れないようにする。
