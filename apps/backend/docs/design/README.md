# backend 画面仕様

このディレクトリは、`apps/backend` が現在提供している画面の仕様をまとめる。
AIによる実装・レビュー時は、日付単位の変更要求である `../features` ではなく、まず本ディレクトリを現行仕様として参照する。

## 仕様一覧

- [シミュレーション画面](./simulation-screen.md): 打順入力、実行、結果表示、共有
- [シミュレーションの仕組み画面](./simulation-guide-screen.md): 入力項目とシミュレーションルールの説明

## 文書の位置付け

- `../features`: 変更時点の要求と完了記録。過去の表現や、まだ画面化されていない案を含む。
- `design`: 現在提供している画面を、画面単位で正規化した仕様。
- HTMLテンプレート: 実装。仕様と実装が食い違う場合は、意図を確認してどちらか一方を修正する。

## 現行仕様へ含めない項目

次の項目は `../features` に記載があるが、現在提供している画面ではないため本仕様へ含めない。

- ログインユーザー向けシミュレーション履歴画面
- ログイン状態によるシミュレーション回数の変更

## 更新規則

画面の追加・変更時は、対応する仕様に少なくとも次を反映する。

1. URLと遷移
2. 表示項目と初期状態
3. 入力制約
4. ユーザー操作と状態変化
5. HTTP通信の入出力
6. エラー時の表示
7. PC・狭幅画面でのレイアウト
