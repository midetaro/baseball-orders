# シミュレーションの仕組み画面仕様

## 基本情報

| 項目 | 仕様 |
|---|---|
| 目的 | シミュレーション画面の入力値、試合進行、性格、戦術、集計結果の意味を利用者へ説明する |
| URL | `GET /simulation-guide` |
| テンプレート | `apps/backend/infrastructure/src/main/resources/templates/simulation-guide.html` |
| 画面見出し | シミュレーションの仕組み |
| 戻り先 | 「打順を組み立てる」リンクから `GET /` へ遷移 |

## 表示内容

画面は次の順序で説明する。

### 1. 打順と成績を入力する

- 1番から9番まで、各選手の成績、性格、戦術を設定する。
- 入力した順番をそのまま打順とする。
- 9人が打順どおりに繰り返し打席へ入る。

### 2. 試合シミュレーションを進める

- 各試合は9回まで行う。
- 3アウトで走者とアウト数を初期化し、次の回へ移る。
- 打席ごとに `盗塁判定 -> バント判定 -> 通常打撃` の順で判定する。
- 盗塁もバントも行わない場合に通常打撃を行い、単打、二塁打、三塁打、本塁打、アウトのいずれかになる。

### 3. 各選手の入力項目

| 項目 | 説明 | 画面入力範囲 |
|---|---|---|
| 出塁率 | 通常打撃でアウト以外になる確率の基準 | 0.01〜0.60 |
| 長打率 | 通常打撃のうち、二塁打、三塁打、本塁打への配分を決める基準 | 0.10〜0.60 |
| バント成功率 | バントを試みた場合の成功確率 | 0.00〜1.00 |
| 盗塁成功率 | 走者が盗塁を試みた場合の成功確率 | 0.10〜0.90 |
| バント・盗塁 | オフの戦術は試みない。オンの場合だけ走者配置と性格に応じて試行を判定する | する／しない |
| 性格 | 通常打撃の配分、盗塁・バントを試みる頻度を変える。入力した成功率そのものは変更しない | 4種類 |

### 4. 性格による違い

| 表示名 | API値 | 説明 |
|---|---|---|
| 標準 | `DEFAULT` | 標準の打撃配分。盗塁は通常の頻度。バントは無死のときに試みる |
| ブンブン丸 | `EAGER_SLUGGISH` | 通常打撃を本塁打寄りにする。本塁打の割合が増える一方、単打などが減り、アウトも増える |
| 盗塁重視 | `EAGER_STEAL` | 盗塁がオンの場合、標準より一塁・二塁走者の盗塁を試みやすくする |
| バント重視 | `EAGER_BUNT` | バントがオンの場合、無死だけでなく一死でもバントを試みる |

### 5. バントと盗塁の結果

- 走者がいる対象場面だけ戦術の試行を判定する。
- 盗塁成功時は走者が次の塁へ進む。
- 盗塁失敗時は盗塁死となり、アウトが1つ増える。
- バント成功時は打者がアウトになり、走者を進める。
- 三塁走者がいる場合はスクイズとして得点する。
- バント失敗時は打者がアウトになる。スクイズ失敗時は三塁走者もアウトになる。

### 6. 複数試合を集計する

- 同じ入力で複数試合をシミュレーションする。
- 平均得点、中央値得点、最大得点、得点分布、本塁打の内訳、バントと盗塁の成否を集計する。
- 各プレーは確率的に決まるため、同じ入力でも実行ごとに結果が変わることを明示する。

## レイアウト

- 本文幅の上限は780pxとし、説明セクションを縦に並べる。
- 入力項目と性格の説明は、広い画面では用語と説明の2列で表示する。
- 画面幅が600px以下の場合は1列へ切り替え、説明文が切れないようにする。
