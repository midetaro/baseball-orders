# シミュレーションの仕組み画面仕様

## 基本情報

| 項目 | 仕様 |
|---|---|
| 目的 | シミュレーション画面の入力値、試合進行、性格、戦術、集計結果の意味を利用者へ説明する |
| URL | `GET /simulation-guide` |
| テンプレート | `apps/backend/infrastructure/src/main/resources/templates/simulation-guide.html` |
| 画面見出し | シミュレーションの仕組み |
| 戻り先 | 「打順を組み立てる」リンクから `GET /` へ遷移 |

## 表示内容

画面は次の順序で説明する。

### 1. 打順と成績を入力する

- 1番から9番まで、各選手の成績、性格、戦術を設定する。
- 入力した順番をそのまま打順とする。
- 9人が打順どおりに繰り返し打席へ入る。

### 2. 試合シミュレーションを進める

- 各試合は9回まで行う。
- 3アウトで走者とアウト数を初期化し、次の回へ移る。
- 打席ごとに `盗塁判定 -> バント判定 -> 通常打撃` の順で判定する。
- 盗塁もバントも行わない場合に通常打撃を行い、単打、二塁打、三塁打、本塁打、四球、三振、凡打のいずれかになる。

### 3. 各選手の入力項目

| 項目 | 説明 | 画面入力範囲 |
|---|---|---|
| 打率 | 安打数を打数で割った割合。四球は打数に含めず別に判定する | 0.01〜0.60 |
| 長打率 | 通常打撃のうち、二塁打、三塁打、本塁打への配分を決める基準 | 0.10〜0.60 |
| バント・盗塁 | オフの戦術は試みない。オンの場合だけ走者配置と性格に応じて試行を判定する。成功率はシミュレーション共通の固定値で入力できない | する／しない |
| 性格 | 通常打撃の配分、盗塁・バントを試みる頻度・場面を変える。バント・盗塁の成功率そのものは変更しない | 6種類 |

### 4. 性格による違い

| 表示名 | API値 | 説明 |
|---|---|---|
| 単打マン | `DEFAULT` | 長打率を二塁打の割合として使い、単打と二塁打だけを打つ。長打は二塁打までに限られる |
| 中距離砲 | `MIDDLE_DISTANCE` | 長打によって増えた塁数を二塁打・三塁打・本塁打へ均等に配分する |
| 長距離砲 | `EAGER_SLUGGISH` | 通常打撃を本塁打寄りにする。中距離砲より本塁打の割合が増える一方、単打などが減る。安打全体の確率は変わらない |
| 高出塁率 | `HIGH_ON_BASE` | 打率は変えず、四球の確率を10%（他の性格は5%）にする。安打の配分は中距離砲と同じ |
| 盗塁重視 | `EAGER_STEAL` | 盗塁がオンの場合、他の性格より二塁走者の盗塁を試みやすくする。打撃は中距離砲と同じ |
| バント職人 | `EAGER_BUNT` | バントがオンの場合、無死だけでなく一死でもバントを試みる。打撃は中距離砲と同じ |

盗塁重視・バント職人以外の性格では、盗塁は通常の頻度、バントは無死のときに試みる。

### 5. バントと盗塁の結果

- 走者がいる対象場面だけ戦術の試行を判定する。
- 盗塁の成功率は70%。成功時は走者が次の塁へ進む。
- 盗塁失敗時は盗塁死となり、アウトが1つ増える。
- 三塁走者がいない場面のバントは進塁バントとなり、成功率は81%。成功時は打者がアウトになり、走者を進める。
- 三塁走者がいる場面はスクイズとなり、25%の確率で試みる。試みた場合の成功率は45%で、成功すれば三塁走者が得点する。
- バント失敗時は打者がアウトになる。スクイズ失敗時は三塁走者もアウトになる。
- 満塁で四球になると押し出しで1点入る。

### 6. 複数試合を集計する

- 同じ入力で複数試合をシミュレーションする。
- 平均得点、中央値得点、最大得点、得点分布、本塁打の内訳、バントと盗塁の成否を集計する。バントは進塁バントとスクイズの成功・失敗、盗塁は二盗成功・三盗成功・盗塁失敗を色分けして表示する。
- 各プレーは確率的に決まるため、同じ入力でも実行ごとに結果が変わることを明示する。

## レイアウト

- 本文幅の上限は780pxとし、説明セクションを縦に並べる。
- 入力項目と性格の説明は、広い画面では用語と説明の2列で表示する。
- 画面幅が600px以下の場合は1列へ切り替え、説明文が切れないようにする。
- 配色は `GET /` のシミュレーション画面と同じアースカラー基調とする。紙のような生成り色を地色とし、見出し・用語・リンクにモスグリーン、強調する数値にテラコッタを使う。
