# 打順組み替え画面仕様

## 基本情報

| 項目 | 仕様 |
|---|---|
| 目的 | 用意されたチームの打者を選び、打順の組み替えとバント・盗塁の選択だけで得点結果を比較できるようにする |
| URL | `GET /`（トップ画面） |
| テンプレート | `apps/backend/infrastructure/src/main/resources/templates/batting-order.html` |
| コントローラ | `SimulationPageController#index`（モデル属性 `teams`） |
| 既定オーダーの保持 | backend の H2（`team_default_batter` テーブル、`schema.sql`・`data.sql` で起動時に投入） |
| 関連画面 | 左メニューから `GET /large-scale`、`GET /single-game`、`GET /simulation-guide` へ遷移 |

試合結果の表示、実行、共有、フィードバックは [シミュレーション画面](./simulation-screen.md) の大規模実行と同じとする（`/simulations` へ送信し、`simulation.ts`（配信時は `/js/simulation.js`）で描画する）。

## 行と表示項目

9行を表示し、各行は次の列をこの順で持つ。

| 列 | 形式 | ドラッグで打者と一緒に移動するか | 送信 |
|---|---|---|---|
| 打順 | 固定ラベル（1番〜9番） | しない（行の位置に固定） | しない |
| ドラッグハンドル | ボタン | — | — |
| 打率 | ラベル | する | `hit_average` |
| 性格 | ラベル（選択不可） | する | `personality` |
| バント | トグル、または強制時はラベル「する」 | する | `bunt_enabled` |
| 盗塁 | トグル、または強制時はラベル「する」 | する | `steal_enabled` |
| メモ | 自由入力（20文字まで） | する | しない（ブラウザ内だけで保持し、backendへ送らない） |

- 打順はドラッグハンドルの左に置き、ドラッグ対象にしない。ハンドルをドラッグするか、ハンドルにフォーカスして上下キーを押すと、打者（打率・性格・強制設定・バント・盗塁・メモ）を移動先の打順へ差し込む。
- 盗塁強制の打者は盗塁を常に「する」として送り、切り替えさせない。バント強制も同様。強制でない打者のバント・盗塁は初期状態「しない」で、打者ごとに切り替えられる。
- 「全員バント」「全員盗塁」は強制でない打者だけを対象に切り替える。性格は変更できないため「性格を初期化」は置かない。
- 入力欄見出しに、9人の打率の平均を「平均打率 0.282」のように小数第3位まで表示する。

## レイアウト

- PC幅（761px以上）: 列幅は `38px 28px 60px 118px 96px 96px 140px`。
- 760px以下: 列幅は `24px 24px minmax(0, .7fr) minmax(0, 1.2fr) repeat(2, minmax(0, .7fr)) minmax(0, 1fr)` とし、390×844 の画面で横・縦ともページスクロールなしに全要素を表示する。強制時のラベルとトグルは項目名を省略して「する」「しない」だけを表示する。
