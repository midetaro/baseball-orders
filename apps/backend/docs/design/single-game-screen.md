# 1試合実行画面仕様

## 基本情報

| 項目 | 仕様 |
|---|---|
| 目的 | 打順ごとの成績を入力し、1試合分のイニングごとの推移を確認できるようにする |
| URL | `GET /single-game` |
| テンプレート | `apps/backend/infrastructure/src/main/resources/templates/single-game.html` |
| ブラウザタイトル | 打順監督 |
| 関連画面 | 「シミュレーションの仕組み」から `GET /simulation-guide`、「大規模実行はこちら」から `GET /large-scale` へ遷移 |

打順入力の行・入力項目・入力制約・一括操作は [シミュレーション画面](./simulation-screen.md) と同じとする（バント成功率・盗塁成功率の入力欄は持たない）。

## 画面構成

ヘッダー、切り替えタブ、打順入力欄、フィードバックなど `/` と機能的に共通する箇所は、`/` と同じ表示にする。ヘッダーには見出し「打順監督」、説明文、関連画面へのリンクだけを表示し、装飾ラベルは置かない。

画面は「打順入力」と「試合結果」の2画面で構成し、画面上部の切り替えタブ（`1 打順入力` / `2 試合結果`）で同一URL内を切り替える。2画面を同時に表示しない。

- 初期表示は打順入力画面のみを表示し、試合結果タブは結果が得られるまで選択できない。
- 「1試合を実行」が成功すると試合結果画面へ切り替え、見出し下に `試合が終了しました。` を表示する。
- 試合結果画面の「打順を編集する」または打順入力タブで入力画面へ戻る。入力値は保持され、そのまま再実行できる。結果が得られた後は試合結果タブから前回の結果へ戻れる。
- 打順入力欄を折りたたむ「入力欄を閉じる」操作は持たない。
- 実行中は二重操作を防ぐため、実行ボタン、タブ、「打順を編集する」を無効にする。

## 試合結果

- 1試合分の状況推移を1プレー1フレームとして自動再生する。各フレームは、スコアボード（イニング・アウトカウント・累積得点）、打席結果、野球場風のフィールド上の走者、打者の打順を表示する。
- 推移のアウト・走者・得点はプレー直前の状況で記録されるため、画面では次の推移からプレー直後の状況を求めて表示する。イニングや試合の最後のプレーは3アウトとし、得点はそのプレーの前後の累積得点の差とする。
- 打席結果と得点差から、フレームごとに次の演出を1つ選ぶ。

| 演出 | 条件 | 表示内容 | 表示時間のプロパティ |
|---|---|---|---|
| 本塁打 | 打席結果が「本塁打」 | 画面のフラッシュ、`HOME RUN!`（4点なら `GRAND SLAM!`）の見出し、場外へ飛ぶ打球、打者走者のダイヤモンド一周、花火、`+N点`、本塁の発光とスコアボードの得点強調 | `home-run-frame-duration-millis` |
| 得点 | 本塁打以外で得点が入った | 安打なら `タイムリー!`、それ以外（押し出し・スクイズ等）は `得点!` の見出し、`+N点`、生還する走者、本塁の発光とスコアボードの得点強調。安打なら打球と打者走者の進塁も表示 | `score-frame-duration-millis` |
| 安打 | 得点のない単打・二塁打・三塁打 | `ヒット!` / `ツーベース!` / `スリーベース!` の見出し、外野へ飛ぶ打球、打者走者の進塁（到達後に塁が点灯） | `hit-frame-duration-millis` |
| バント成功 | 得点のない「バント成功」（進塁バント） | `バント成功!` の見出し、本塁前に転がる打球、進塁した走者の塁の点灯 | `bunt-frame-duration-millis` |
| なし | 上記以外 | 演出なし | `frame-duration-millis` |

- 表示時間は `baseball-orders.rendering.single-game` 配下のプロパティで local・prod ごとに設定する。
- アニメーションの直上に再生速度の切り替え（`遅い` / `普通` / `速い`）を置く。初期値は `普通` で、プロパティどおりの表示時間で再生する。`遅い` は2倍、`速い` は半分の時間でフレームを切り替え、フレーム内の演出アニメーションも同じ倍率で再生する。再生中に切り替えると、表示中のフレームの演出と次のフレームからの表示時間に反映する。
- スコアボードは再生開始時から試合全体のイニング別得点とR・H・Eを表示し、再生中のフレームのイニングを見出しと得点欄の色で示す。最後のフレームの表示時間が過ぎたら強調を外す。打球の方向は推移の順番で左・中・右を巡回し、同じ結果なら同じ表示になる。
- OSの「視差効果を減らす」（`prefers-reduced-motion: reduce`）が有効な場合は演出のアニメーションを止め、見出しのみ表示する。
- 打順成績表は9行（1番〜9番）×イニング列で、各打席の結果を表示する。安打・得点・本塁打の打席はそれぞれ色分けする。列が収まらない場合は表内で横スクロールする。
- 状況推移が空の場合は「試合結果はありません。」を表示する。

## レイアウト

- PC幅（761px以上）では打順入力画面を中央のコンパクトなカードとして置き、試合結果画面ではアニメーションを左、打順成績表を右に横並びにする。
- 760px以下では打順入力を `/` と同じく打者ごとに一行で並べ、試合結果ではアニメーションの下に打順成績表を置く。
- PC 1280×800、スマホ 390×844 の両方で、入力・結果ともにページスクロールなしで全要素が見える。
