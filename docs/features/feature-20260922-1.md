# Feature name

Status: in_progress

# 変更の概要
シミュレーション機能の拡充
1. 対象はsimulator/domainのみ
2. hittingのアウトを廃止し、三振と凡退に分割
3. hittingのresultに四球を追加。出塁塁は四つのヒットと四球に分割される。直近の塁が埋まっていればそのランナーを進塁させる
4. 三振は進塁なし。
5. 凡退は一定確率で既存のランナーが進塁。この確率は既存の実装を参考にする

## Goal
- baseball-orders-reviewをクリアすること

## In scope
- simulator

## Out of scope
- backend

## Current behavior
- hittingの結果にアウトがある

## Expected behavior
- hittingのアウトを三振と凡退に分割する
- hittingに四球を追加し、四球率は `min(5%, 出塁率)` とする
- 非出塁の25%を三振、残りを凡退とする
- 四球は一塁から連続して埋まった走者だけを押し出す
- 三振では走者を進塁させない
- 凡退では既存の進塁確率（一・二塁走者20%、三塁走者10%）と進塁ルールを維持する

## Acceptance criteria
- `BattingResult` に `OUT` が存在せず、`STRIKEOUT`、`BATTED_OUT`、`WALK`、4種類の安打が存在すること
- 1回の乱数抽選で、四球率が `min(5%, 出塁率)` になる境界を自動テストで検証すること
- 非出塁領域の先頭25%が三振、残り75%が凡退になる境界を自動テストで検証すること
- 8種類すべての走者配置で、四球が一塁から連続する走者のみを進塁させ、満塁時だけ1得点を加算すること
- 走者がいる状態の三振で、アウトだけが増え、走者配置が変化しないこと
- 凡退時の進塁成功・失敗と三死目の非進塁を、既存確率の境界値を用いた自動テストで検証すること
- Simulatorのフォーカステストと標準検証が成功し、モジュール依存関係に変更がないこと
- `baseball-orders-review` によるレビューで blocking finding がないこと
